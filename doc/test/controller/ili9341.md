# TestControllerILI9341 case design（Controller\<ILI9341, M, N\> UT）

> 对应 suite：`tests/Controller/TestControllerILI9341.cpp`；算法 spec：Controller spec。

## Mock 矩阵与本 suite 范围

- SPI 侧 → **MockBus**（`tests/support/mockBus.hpp`，duck-type：记录每次 `send`/`sendBulk` 的字节与次数、read 预置 FIFO）。
- GPIO 侧（DC/RST）→ hal_stub：`hal::g_transcript.gpio` 记录每次 `HAL_GPIO_WritePin`。
- 断言按 **Controller spec 固定发送粒度**（spec §5/§7 契约）：每个命令 1 次 send、每组参数 1 次 send、**像素段 = 1 次 sendBulk（分块迁入 Bus，本层不再拆分）**、fillScreen 逐行（2×M 字节）1 次 send。
- **不含 bringUp/上电序列**（私有、装配期触发，归 MT，见 test/architecture §1）。

## 夹具（fixture）

```cpp
class TestControllerILI9341 : public ::testing::Test {
  protected:
    void SetUp() override {
        hal::g_transcript.reset();
        bus.reset();
    }
    GPIO_TypeDef dcPort;
    GpioPin dc{&dcPort, GPIO_PIN_0};
    MockBus bus;
    Controller<ControllerType::ILI9341, 240, 320> ctrl{dc};  // Controller 只持 DC；RST 归 PanelMgr
};
```

横屏（320×240）/小分辨率（240×100）用例在用例内构造局部 Controller（复用 `bus`）。

## 支撑说明

- **发送粒度即 spec 契约**（Controller spec §5/§7：命令/参数各 1 次 send、像素段 1 次 sendBulk、fillScreen 逐行 2×M）——本文按该契约断言；spec 若改粒度，本文与用例须同步。
- fillScreen 行缓冲 2×M（栈上，编译期定尺寸），单次 send ≤65535；调用方无缓冲负担（spec §5）。
- 刻意不测：bringUp（归 MT）；`readID` 的期望值比对（调用方职责，spec §5）；CS（归 Driver）。
